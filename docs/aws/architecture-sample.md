# 最小構成の例（Webアプリ）

## この章でできるようになること

- AWSの主要サービスの並びをイメージできる
- 「どこで何が起きるか」を会話で説明できる
- 最低限の構成図を言葉で再現できる

## まずはこの形を覚える

```
ユーザー
  ↓
（インターネット）
  ↓
ロードバランサー
  ↓
アプリ（EC2/ECS/Lambda）
  ↓
データベース（RDS/DynamoDB）
```

## ざっくり役割

- ロードバランサー: アクセスを複数のアプリへ振り分ける
- アプリ: 画面やAPIの処理を担当
- データベース: データを保存する

## 会話で使える言い方

- 「入口はロードバランサー、真ん中がアプリ、裏側がDB」
- 「アプリの置き方はEC2でもECSでもLambdaでもOK」
